# Pvz

## Запуск

Сначала клонируйте проект с GitHub:

```sh
git clone https://github.com/egorolkhov/pvz
cd market
```

### **Запуск с Docker**
Для развертывания сервиса используйте команду:

```sh
docker-compose up --build
```

Структура проекта
```sh
pvz
├── 📂 cmd
│   └── 📄 main.go                            # Точка входа, запуск сервера, инициализация зависимостей
│
├── 📂 internal                              
│   ├── 📂 config
│   │   └── 📄 config.go                      
│   │
│   ├── 📂 handlers                           # Обработчики HTTP-запросов
│   │   ├── 📂 common                         # Общие обработчики и вспомогательные функции
│   │   ├── 📂 pvz                            # Обработчики для пунктов выдачи заказов
│   │   ├── 📂 receptions                     # Обработчики приёмок товаров
│   │   ├── 📂 user                           # Обработчики авторизации и управления пользователями
│   │   └── 📄 routes.go                      # Регистрация всех маршрутов
│   │
│   └── 📂 manager                            # Слой сервисов и менеджер зависимостей
│       ├── 📂 mocks                          
│       ├── 📂 services                       # Сервисный слой, содержащий бизнес-логику
│       │   ├── 📂 pvz                        # Сервисы для работы с ПВЗ
│       │   ├── 📂 reception                  # Сервисы для работы с приемками
│       │   └── 📂 user                       # Сервисы для работы с пользователями
│       └── 📄 manager.go                     # Единый менеджер зависимостей
│
├── 📂 migrations                             # Файлы миграций для базы данных
│
├── 📂 pkg                                    
│   ├── 📂 auth                               # Пакет для работы с авторизацией и JWT-токенами
│   └── 📂 logger                             # Логирование
│
├── 📂 middleware                             # Промежуточные обработчики
│
├── 📂 models                                 # Структуры данных, используемые в приложении
│
├── 📂 storage                                # Работа с БД и хранением данных
│   ├── 📂 migration                           
│   ├── 📂 mocks                              # Mock-объекты для storage
│   ├── 📂 transactionManager                 
│
├── 📂 tests                                  # Интеграционные тесты приложения                           

```
